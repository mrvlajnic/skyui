# Overview

SkyUI is a next-generation infotainment interface designed for future Veltron vehicles.

The project focuses on creating a clean, premium and highly modular automotive user interface inspired by modern vehicle operating systems while maintaining its own identity.

This is **not** a mobile application.

SkyUI is designed as a complete in-vehicle operating system.

# Running the Project

Clone the repository

```bash
git clone https://github.com/VeltronCars/SkyUI.git
```

Open the project

```bash
cd SkyUI
```

Install dependencies

```bash
flutter pub get
```

Run

```bash
flutter run
```

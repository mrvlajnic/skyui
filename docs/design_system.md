# SkyUI Design System

Version: 0.1 Alpha

---

# Purpose

This document defines the visual language of SkyUI.

Every interface inside SkyUI must follow these rules.

Consistency is more important than creativity.

---

# Design Philosophy

SkyUI is designed for a premium automobile.

It should feel:

- Modern
- Premium
- Minimal
- Calm
- Driver Focused
- Elegant

The interface must never feel like a mobile application.

Think:

Luxury vehicle

not

Android tablet.

---

# Visual Identity

Keywords

Premium

Minimal

Luxury

Dark

Soft

Elegant

Technical

Driver First

---

# Color Palette

## Primary Background

Very Dark

Almost Black

---

## Secondary Background

Slightly lighter than the primary surface.

Used for cards.

---

## Accent Color

Veltron Yellow

This is the only strong accent color.

Use it for:

- Active navigation
- Selected items
- Progress bars
- Highlights

Never overuse it.

---

## Text Colors

Primary

White

Secondary

Light Gray

Disabled

Dark Gray

---

## Status Colors

Success

Green

Warning

Orange

Error

Red

Information

Blue

Use status colors only for status.

Never for decoration.

---

# Typography

Typography should feel automotive.

Clean.

Readable.

No decorative fonts.

Hierarchy

Display

Page Titles

Section Titles

Body

Caption

Small Labels

---

# Layout Philosophy

Every page follows:

Header

↓

Content

↓

Optional Bottom Panel

Sidebar always remains visible.

---

# Spacing System

Use consistent spacing.

Allowed spacing values:

4

8

12

16

24

32

48

64

Avoid random values.

---

# Corner Radius

Cards

Medium

Buttons

Medium

Dialogs

Large

Avoid sharp corners.

Avoid extreme roundness.

---

# Elevation

SkyUI uses soft elevation.

Never use aggressive shadows.

Instead use:

Soft borders

Subtle gradients

Soft highlights

---

# Animations

Animations should feel smooth.

Never flashy.

Recommended durations:

Fast

150ms

Normal

250ms

Large

350ms

Transitions should be subtle.

---

# Sidebar

Sidebar is always visible.

Contains:

Logo

Navigation

Settings

Navigation icons remain centered.

Only one item is active.

---

# Header

Header contains:

Brand

System Status

Clock

Connectivity

Bluetooth

Battery

WiFi

Notifications

Header should remain minimal.

---

# Cards

Cards are the foundation of the interface.

Every card should contain:

Title

Content

Optional Actions

Optional Status

Cards should never feel crowded.

---

# Buttons

Buttons should be simple.

Primary

Accent

Secondary

Dark

Danger

Red

Disabled

Gray

Avoid excessive borders.

---

# Icons

Icons should be:

Simple

Thin

Modern

Consistent

Do not mix icon styles.

---

# Images

Images should be high quality.

Use:

Vehicle renders

Maps

Album covers

Weather

Avoid low resolution images.

---

# Vehicle Images

Vehicle renders should always be:

High resolution

Transparent background

Centered

Never stretched.

---

# Navigation

Navigation should require minimal driver attention.

Large touch targets.

Simple hierarchy.

Minimal interaction.

---

# Information Density

Show only necessary information.

Hide advanced information until requested.

Never overload the user.

---

# Responsiveness

SkyUI must support:

Desktop

Vehicle Displays

Ultrawide Displays

Future Android Automotive Displays

Components should scale naturally.

---

# Accessibility

Maintain readable contrast.

Large touch areas.

Readable typography.

Avoid tiny icons.

---

# Glass Effects

Allowed.

Should remain subtle.

Never blur the entire interface.

---

# Gradients

Gradients are allowed.

Prefer image backgrounds over expensive runtime effects during development.

Heavy visual effects can be introduced later if performance allows.

---

# Component Rules

Every reusable component belongs inside widgets/.

Never duplicate components.

If used more than once:

Extract.

---

# Screen Rules

Every screen should answer:

Where am I?

What is important?

What can I do?

Everything else is secondary.

---

# Design Don'ts

Never use bright backgrounds.

Never create clutter.

Never overuse yellow.

Never mix icon packs.

Never create giant buttons.

Never use random spacing.

Never use random font sizes.

Never invent colors.

Never hardcode UI values.

---

# Design Goals

The interface should feel:

Fast

Premium

Comfortable

Confident

Modern

Effortless

The user should focus on driving.

The interface should quietly assist.
